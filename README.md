## Initial setup (Docker)

1. In text editor of your choice, create a ```.env``` file, following the ```.env.example``` guidelines.
2. Open a terminal and ensure you are in the ```virus_the_game/``` directory.
3. Run the following docker command:

```bash
docker compose up
```

Now, the app is accessible on all the LAN connected devices on
[http://{LAN_HOST_IP}:8000](http://{LAN_HOST_IP}:8000)
